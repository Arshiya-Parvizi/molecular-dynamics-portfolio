## Selected Results

The repository includes reproducible Python workflows built around selected molecular dynamics analysis outputs. The figures below highlight several representative analyses from the project.

### Ligand–Membrane Spatial Distribution

Normalized density profiles allow components with very different absolute density magnitudes to be compared by spatial position and profile shape.

![Normalized density profile comparison](figures/normalized_density_comparison.png)

The selected 2-bromothymol system shows distinct spatial distributions for the analyzed components along the bilayer-normal coordinate. Normalization emphasizes relative peak positions rather than absolute density magnitude.

### Radial Distribution Function

Radial distribution functions were used to examine preferred distances between selected molecular groups.

![Thymol P8 radial distribution function](figures/RDF_THYM_2_P8.png)

The selected thymol–P8 RDF shows a pronounced maximum near 0.47 nm, indicating enrichment at this separation. RDF peaks are interpreted as structural distance preferences rather than direct evidence of binding.

### Hydrogen-Bond Occupancy

Selected ligand–membrane and ligand–water hydrogen-bond interactions were compared using frame-based occupancy.

![Hydrogen-bond occupancy comparison](figures/hbond_occupancy_comparison.png)

The analysis demonstrates how specific polar interactions can range from persistent to intermittent or absent depending on the selected donor–acceptor pair.

### Lipid-Tail Ordering

Segmental lipid order parameters provide a measure of orientational ordering along selected lipid tails.

![Lipid order-parameter comparison](figures/order_parameter_comparison.png)

The selected profiles show system-dependent variation in lipid-tail ordering. Absolute comparisons are interpreted cautiously when lipid or atom selections differ.
